# بوت تخزين وتوزيع التطبيقات (File Store Bot)

بوت تيليجرام احترافي بلغة بايثون ومكتبة Pyrogram لتخزين وتوزيع الملفات والتطبيقات عبر أزرار شفافة وروابط مباشرة سريعة، مع لوحة تحكم كاملة بالأزرار الشفافة للأدمن وميزة إنشاء منشورات التطبيقات المباشرة في القنوات.

---

## 🌟 الميزات والإمكانيات

- 📝 **إنشاء منشورات التطبيقات التفاعلية:** إرسال صورة/شرح التطبيق ثم إرسال ملفه، ليقوم البوت بإنشاء زر شفاف باسم `اضغط هنا للتحميل 📥` ونشره تلقائياً في قنوات النشر العامة المحددة.
- 🎛 **لوحة تحكم شفافة كلياً للأدمن:** إدارة كاملة للبوت دون الحاجة لأية أوامر نصية معقدة.
- 📢 **إدارة قنوات النشر العامة:** إضافة وإدارة قنوات متعددة يتم نشر منشورات التطبيقات فيها تلقائياً.
- 📊 **إحصائيات شاملة:** متابعة عدد المستخدمين، إجمالي الملفات، وإجمالي عمليات التحميل، وقنوات النشر والاشتراك الإجباري.
- 📢 **إذاعة عامة متقدمة (Broadcast):** إرسال واستحداث الإذاعات لجميع مستخدمي البوت (نصوص، صور، فيديو، صوت، رسائل موجهة) مع تقرير فوري بنسبة النجاح والفشل.
- 🔐 **إدارة متعددة للاشتراك الإجباري:** إضافة وتفعيل/تعطيل أو حذف قنوات متعددة للاشتراك الإجباري بضغطة زر.
- 📁 **إدارة الملفات المرفوعة:** تصفح أحدث الملفات بالترقيم الصفيحي، معرفة إحصائيات التحميل لكل ملف، واستعلام برقم الـ ID أو حذف الملفات.
- ⚡ **تخزين فوري وتوليد الروابط:** بمجرد إرسال الأدمن للملف للبوت يتم رفعه وإعطاؤه الرابط المباشر تلقائياً.

---

## 🚀 طريقة التثبيت والتشغيل

### 1. الحصول على البيانات المطلوبة
- `API_ID` و `API_HASH`: من موقع [my.telegram.org](https://my.telegram.org)
- `BOT_TOKEN`: أنشئ بوتًا عبر [@BotFather](https://t.me/BotFather) وخذ التوكن
- `ADMIN_IDS`: آيدي حسابك على تيليجرام
- `STORAGE_CHANNEL_ID`:
  1. أنشئ قناة خاصة جديدة (قناة التخزين)
  2. أضف بوتك كـ **أدمن** فيها (بصلاحية إرسال الرسائل)
  3. احصل على آيدي القناة (يبدأ بـ `-100`)
- `BOT_USERNAME`: يوزر البوت بدون `@`

### 2. التثبيت على السيرفر (VPS)

```bash
# الانتقال لمجلد المشروع
cd filestore_bot

# إنشاء البيئة الافتراضية وتفعيلها
python3 -m venv venv
source venv/bin/activate

# تثبيت الحزم المطلوبة
pip install -r requirements.txt

# إعداد ملف البيئة
cp .env.example .env
nano .env   # قم بتعبئة بيانات الاعتماد
```

### 3. التشغيل التجريبي

```bash
python3 bot.py
```

إذا ظهرت الرسالة `Bot is starting...` يعمل البوت بنجاح!

### 4. التشغيل الدائم عبر systemd

```bash
sudo cp filestorebot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable filestorebot
sudo systemctl start filestorebot
```

## 📖 دليل الاستخدام

### للأدمن (المدير):
1. **لوحة التحكم:** عند الدخول للبوت أو إرسال `/start` بدون رابط، سيظهر زر **"🎛 فتح لوحة التحكم"**.
2. **إنشاء منشور تطبيق:**
   - اضغط على زر **"📝 إنشاء منشور تطبيق"**.
   - أرسل منشور التطبيق (صورة الشرح / نص الشرح).
   - أرسل ملف التطبيق المطلوب.
   - يعرض البوت معاينة سريعة للمنشور مع زر `اضغط هنا للتحميل 📥` وزر تأكيد النشر في جميع قنوات النشر العامة المحددة.
3. **رفع سريع للملفات:** قم برفع أي ملف للبوت مباشرة للحصول على رابط التحميل المباشر فوراً.
